# File_handling_c
# 📂 File Handling & Data Structures in C

A collection of C programs developed to practice **File Handling, Data Structures, CRUD operations, and problem-solving concepts**.

This repository contains programs created as part of my **FODS (Fundamentals of Data Structures)** learning and coursework.

---

## 🚀 About the Repository

This repository focuses on implementing important programming and data structure concepts using **C**.

The programs demonstrate how to:

- 📁 Create, read, write and update files
- 🔄 Perform CRUD operations
- 🔗 Implement Linked Lists
- 📚 Implement Stack and Queue
- 🌳 Implement Binary Trees and Binary Search Trees
- 🧠 Practice problem-solving and logical thinking
- 💾 Store and retrieve data using files
- ⌨️ Handle user input and validation

---

## 🛠️ Concepts Covered

### 📂 File Handling

- File creation
- Reading from files
- Writing to files
- Appending data
- Updating records
- Searching records
- File-based data storage

### 🔄 CRUD Operations

CRUD stands for:

- **C** → Create
- **R** → Read
- **U** → Update
- **D** → Delete

These operations are implemented using C programs and file-based storage.

### 🔗 Data Structures

- Arrays
- Linked Lists
- Stacks
- Queues
- Binary Trees
- Binary Search Trees (BST)
